# Changelog

## 0.1.0

- Extracted the ontology and O-SQL compiler as a standalone project.
- Added a single `ontology` CLI, a minimal school example and language-first docs.
- Preserved semantic identity, relational lowering, PostgreSQL constraints and
  the query compiler with their existing tests.
- Added standalone Make, Nix, CI and native-binary release packaging.
- Kept application compilation on an experimental branch.
